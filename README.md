# 🌤 Weather App

Прогноз погоды с живой атмосферой. Реагирует на реальную погоду — солнце, дождь, снег, гроза меняют фон и эффекты.

![preview](preview.png)

## ✨ Возможности

- 🌍 **Поиск любого города** с автодополнением и флагами стран
- 📍 **Геолокация** одной кнопкой
- 🌡 **Текущая погода** — температура, ощущения, влажность, ветер, давление
- ⏱ **Почасовой прогноз** на 24 часа с вероятностью осадков
- 📅 **Прогноз на 5 дней** с визуальными барами температуры
- ☀️ **Дуга солнца** — восход, закат, позиция светила в реальном времени
- 🌿 **Качество воздуха** (AQI, PM2.5)
- 🎨 **SVG-иконки** с градиентами вместо эмодзи
- 🌈 **Живая атмосфера** — частицы дождя, снежинки, вспышки молний, звёзды
- 📱 **Адаптив** под мобильные и десктоп
- 🌓 **Тёмная тема** по умолчанию

## 🛠 Технологии

- Чистый **HTML / CSS / JavaScript** — без фреймворков и сборщиков
- **[Open-Meteo](https://open-meteo.com/)** — API погоды и геокодинга
- **[wttr.in](https://wttr.in/)** — резервный источник данных
- **Cloudflare Workers** — прокси для обхода блокировок

## 🚀 Запуск

Просто открой `index.html` в браузере.

Или через Live Server в VS Code.
